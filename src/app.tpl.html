Compliance per proses

Compliance = COMPLY dibagi (COMPLY + NON-COMPLY), N/A tidak dihitung. Bagian ini selalu menampilkan semua lokasi DC.

Jenis gap dan pemiliknya

Satu temuan masuk ke satu jenis. Klasifikasi ini usulan awal dari isi temuan dan catatan auditor, jadi perlu dikonfirmasi auditor. Klik kartu untuk menyaring daftar temuan.

Heatmap tahap proses x status

Intensitas warna adalah porsi status itu dalam tahap. Klik baris untuk melihat temuannya, atau "Alur" untuk membuka tahap alurnya.

Peringkat NON-COMPLY

Jumlah temuan NON-COMPLY, dengan porsinya terhadap seluruh langkah aktor, kategori, atau SOP itu. Klik batang untuk menyaring daftar temuan.

Tema gap lintas proses

Sembilan tema dari prompt dan satu tambahan dari data (SOP tidak sesuai praktik). Klik chip langkah untuk membukanya di Peta. Catatan "Verifikasi" memuat selisih dengan prompt jika ada.

Kualitas data

Flag QA tidak mengubah data sumber. Bagian ini juga memuat hal yang saya temukan saat verifikasi sebagai bahan tinjau ulang auditor.
